We use remote word for github and local word for 
our device i.e. laptop, pc

** Clone **
Cloning a repository on our local machine

// git clone <https_link>


** Status **
Viewing status of the current folder/file

// git status


** Untracked File **
new files that git doesn't track yet


** modified **
changes are made in the file


** staged **
file is ready to be committed


** unmodified **
unchanged


** flow **
change/ new file  --->  add(staged)  --->  commit(changes saved)


** add **
adds new or changed files in your working directory 
to git staging area

// git add <file_name>
// git add . (for adding all the files in the folder to staging area)


** commit **
it is the record of change

// git commit -m "commit message"


** push **
upload local repo content to remote repo

// git push remote_name branch_name

// git push origin main

Here remote-name(origin) is the name of the remote 
repository that you want to push to and branch-name(main) 
is the name of the branch that you want to push.



** IMP **
Suppose if we make a new repo and want to add that 
new repo in github then we have to first init it then 
add origin then add and then commit and then push


** init **
used to create a new git repo

// git init

// git remote -v

// git remote add origin <link> (to add a remote repo from where pull and push should happen)

// git remote set-url <link> (to change the remote repo)

// git remote -v (to verify branch)

// git branch (to check branch)

// git branch -M main (to rename branch)

// git push origin main

// git push -u origin main
(it is used to make an upstream with the repo
so that we dont have to always write origin main
just writing git push after that will also do)



*** Git Branches ***

Branch Commands : 


// git branch  (to check bracnh)

// git branch -M main  (to rename branch)

// git checkout branch name  (to navigate)

// git checkout -b branch_name  (to create new branch)

// git branch -d branch_name  (to delete branch)
(used to delete after after merging)

// git branch -D branch_name  (to to delete before merging)


// git diff branch_name  (to compare commits, branches, files and more)

// git merge branch_name  (to merge two branches)



*** Pull Request *** (PR)

It lets you tell others abiut changes you have pushed to a branch in repository on github

PR is handled on github website
